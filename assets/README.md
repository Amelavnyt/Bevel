# Assets

Icons, standards tables (hole and thread data, as RON) and example scripts
used by the application. Each phase adds what it needs; see
[../docs/ROADMAP.md](../docs/ROADMAP.md).

## Icons

`icons/` holds the UI icon set: 32×32 SVGs in one flat style (isometric
bodies in three shades of the signature teal #2D8985 with one outline, the
part an operation affects in the light accent tint #8FE0B4, light line
icons for app commands). They are drawn for Bevel and licensed with the project.
