# Assets

Icons, standards tables (hole and thread data, as RON) and example scripts
used by the application. Each phase adds what it needs; see
[../docs/ROADMAP.md](../docs/ROADMAP.md).

## Icons

`icons/` holds the UI icon set: 32×32 SVGs in one flat style (three-tone
teal-grey isometric bodies with one outline, the part an operation affects
in the accent green #77C89D, light line icons for app commands; the logo
uses the signature teal #2D8985). They are drawn for Bevel and licensed with the project.
