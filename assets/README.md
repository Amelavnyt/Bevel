# Assets

Icons, standards tables (hole and thread data, as RON) and example scripts
used by the application. Each phase adds what it needs; see
[../docs/ROADMAP.md](../docs/ROADMAP.md).

## Icons

`icons/` holds the UI icon set: 32×32 SVGs in one style (isometric bodies
in blue, the part an operation affects in orange, light line icons for app
commands). They are drawn for Bevel and licensed with the project.
